What is this?

A language model playing Pokémon on a Game Boy emulator, on a server at home. It never presses buttons directly: it writes small Python scripts, runs them in a sandbox and looks at what happened, building up a library of scripts as it goes. It isn't told where anything is in memory, and keeps its own notes because its context is regularly cleared.

The game only moves when a script runs, so the screen holds still while the model is thinking. Each step is replayed here at game speed, a few seconds behind.

The party, trainer and map next to it are read straight out of the game's memory at the end of each step, so they change as the clip on screen does. Sprites are from PokeAPI.
